# 2PIK — HTML VERSION

Это полностью статический сайт на HTML/CSS. React, Vite и Node.js НЕ нужны.

## Структура

- `index.html` — главная
- `roster.html` — состав
- `rules.html` — правила
- `join.html` — вступление
- `clans/` — отдельные страницы каждого клана
- `assets/style.css` — общий дизайн

## Каждый клан — отдельный HTML-файл

Например:

`clans/2pik-main.html`

`clans/2pik-metro.html`

`clans/2pik-greshnik.html`

Открываешь нужный HTML-файл в любом редакторе и меняешь только данные этого клана.

## Как добавить новый клан

1. Скопируй любой файл из `clans/`.
2. Переименуй его, например в `2pik-speed.html`.
3. Измени название, логотип, описание, лидера, количество участников и остальную информацию.
4. В `roster.html` добавь карточку со ссылкой на новый файл.

## Запуск

Можно просто открыть `index.html` браузером. Для публикации можно загрузить всю папку на обычный HTML-хостинг.
